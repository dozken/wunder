# Quick Start Guide

This guide will help you get started with the Wunder Challenge: LOB Predictorium.

## 1. Get the starter pack

**macOS/Linux**
```bash
curl -L https://files.wundernn.io/wnn_predictorium_starterpack.tar.gz | \
tar -xz && \
cd competition_package
```

**Windows**
or download the archive manually:
[wnn_predictorium_starterpack.zip](https://files.wundernn.io/wnn_predictorium_starterpack.zip)
[wnn_predictorium_starterpack.tar.gz](https://files.wundernn.io/wnn_predictorium_starterpack.tar.gz)

*(slow download? try mirror-1/mirror-2)*

### What's inside

```
wnn_predictorium_starterpack/
├── datasets
├   ├── train.parquet
├   └── valid.parquet
├── example_solution
├   ├── baseline.onnx
├   └── solution.py
├── README.md
└── utils.py
```

Here's some things worth noting:
*   `datasets/`: a training and validation datasets to build and test your models locally.
*   `utils.py`: contains helper classes (like `DataPoint`) and the scoring function. **We ask you not to change this file**, as it will create inconveniencies for you at the final stage.
*   `examples_solution/`: a minimal working example to show the required submission format.

## 2. Set up your environment and packages

We strongly recommend using a virtual environment to keep your project dependencies tidy and avoid conflicts. Probably any Python 3.10+ will do. Submissions will be evaluated in a Docker container based on `python:3.11-slim-bookworm` image.

**Set up the env:**

*macOS/Linux*

*Windows*

```bash
python -m venv env
source env/bin/activate
```

**Then install the required packages:**
```bash
pip install numpy pandas pyarrow tqdm onnxruntime torch
```

## 3. Explore the data

The dataset is provided in Parquet format.

*   `datasets/train.parquet` — training data (10,721 sequences)
*   `datasets/valid.parquet` — validation data (1,444 sequences)

Each sequence has 1000 steps. The first 99 steps are for warm-up/context, and you predict for steps 99-999.

## 4, Run the example solution

We provided a baseline solution in `example_solution` folder.

```bash
cd example_solution
python solution.py
```

This script will load the validation data and the pre-trained `baseline.onnx` model, run inference, and calculate the Pearson Correlation score.

> **FUN FACT**
> This baseline was generated by an LLM Assistant. We asked it to create a Vanilla GRU model and optimized for inference speed (ONNX) to meet the competition's time limits. It was trained on the full training dataset and tuned using the provided validation set.

## 5. Submit

Zip your `solution.py` and model artifacts:

```bash
zip -r submission.zip solution.py baseline.onnx
```

Go to the submit page and send your solution for scoring.

🎉 ta-daa, you're awesome

## 6. Develop your own model

1.  Create your own `solution.py` implementing the `PredictionModel` class.
2.  Train your model using `datasets/train.parquet`.
3.  Validate using `datasets/valid.parquet`.
4.  Export your trained model (e.g., to ONNX) for fast inference.

Good luck with the challenge! We're excited to see what you build.
